# human-nature

Analysis code for a six-country survey (Canada, Panama, Poland, the Netherlands, Spain, Sweden; n = 2,513) on human–nature relationships.

- `paperII/scripts/` — replication pipeline for Paper II (perceived vs ideal human role). See its README for how to run it.
- Raw survey data are not in this repository (they contain IP addresses and exact timestamps); a de-identified release is planned.
